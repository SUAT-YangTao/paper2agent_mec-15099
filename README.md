# mec-15099 — Paper2Skill reading package

A reading package for a single paper, assembled with Paper2Agent's **Paper2Skill**
pipeline. Both source PDFs were parsed page by page, every page was reviewed
against its own rendered image, and the assembled result was checked by the
pipeline's strict verifier before being published here.

## Source paper

Foote, A. D. et al. (2019). **Killer whale genomes reveal a complex history of
recurrent admixture and vicariance.** *Molecular Ecology* 28:3427–3444.
doi:[10.1111/mec.15099](https://doi.org/10.1111/mec.15099)

Two documents were converted: the 18-page main article and the 18-page
supplementary information.

**Neither source PDF is included in this repository.** They are the publisher's
copyrighted material; download them from the DOI above.

## Structure

| Path | What it is |
| --- | --- |
| `mec-15099-paper/SKILL.md` | Entry point. Sets up the reading workflow: locate a heading or topic, read a bounded passage, then answer. |
| `mec-15099-paper/references/index.md` | Navigation index. Every heading in both documents, each with a note on what evidence that section holds. |
| `mec-15099-paper/references/paper.md` | The main article as reviewed Markdown (~96 KB). |
| `mec-15099-paper/references/supplement.md` | The supplementary information as reviewed Markdown. |
| `mec-15099-paper/assets/figure/` | Figures 1–5, plus the two display formulas from section 2.7 — the *D*-statistic and the *f*4-ratio (7 JPEGs). |
| `mec-15099-paper/assets/supp_figs/` | Supplementary figures S1–S15 (15 JPEGs). |
| `mec-15099-paper/assets/supp_table/` | Supplementary Table S1 and its continuation, transcribed to CSV, plus a table-of-contents CSV. |
| `tools/` | The three scripts written for this conversion — see below. |

29 files in the package, about 2.4 MB.

## Verification

The package was built with `--require-reviewed` and passed `verify --strict`
(exit 0):

| Check | Result |
| --- | --- |
| Status | `reviewed_with_limitations` |
| Mechanical checks | passed |
| Sources agent-reviewed | 2 of 2 |
| Artifact checks (images, CSVs) | 25 of 25 match the source conversion |
| Adjudicated diagnostics | 12 applied (9 main, 3 supplement), 0 stale |

`reviewed_with_limitations` is not a failure: it records that the review found
things worth documenting rather than nothing at all. The twelve adjudications
are all normaliser artefacts, not content errors — the source text layer's
zero-width spaces inside DOIs, `U+2010` in ORCIDs and grant numbers, en dashes
in page ranges, and the Greek delta in a figure caption. Each is recorded with
the reason it was accepted.

## Known limitations

- `references/index.md` lists an `assets/table/` directory for main tables. The
  main article contains no tables, so that directory does not exist here. (The
  index is generated by the pipeline template, which advertises the path
  unconditionally.)
- `assets/supp_table/supplementary-table-1-continued.csv` has no header row;
  the header is in `supplementary-table-1.csv`.
- Table CSVs retain internal blank rows and caption rows — consult the document
  notes before treating every row as data.

## Fidelity notes

The text is a transcription of what the source PDFs print, so some things that
look like transcription errors are the source's own:

- the funding note reads "a **Swisss** National Science Foundation grant"
  (printed that way on both pages it appears);
- the Results cross-reference "(Figure S2b)" and the Discussion's
  "(Figure 2d)", which do not obviously name the figures they describe;
- the Lefort et al. (2015) reference title is missing its leading program name
  and begins abruptly at "2.0: A comprehensive, accurate, and fast…".

These are preserved rather than silently corrected.

## Usage

Copy `mec-15099-paper/` into a skills directory (for Claude Code,
`.claude/skills/`), then ask questions about the paper. The skill registers as
`mec-15099` and points at its own navigation index.

Without a skill runner you can still read the package directly: start at
`mec-15099-paper/references/index.md`, use it to pick a section, then read that
passage in `paper.md` or `supplement.md`.

## Tools

Three scripts were written for this conversion. Each takes a Paper2Skill review
work directory as its argument and contains no machine-specific paths. They are
kept here to document how the package was corrected, not as a general-purpose
toolkit.

| Script | Problem it solved |
| --- | --- |
| `normalize_headings.py` | The extractor emitted every heading at level 1, including the title, so the generated index listed only the masthead and two metadata blocks. This re-levels the hierarchy to title / section / subsection. |
| `apply_reading_order.py` | Two-column extraction had split five figures from their captions and cut six sentences in half across figure seams. This authors the document-level `reading_order` that restores the sequence, plus the prose joins that then become legal. |
| `build_navigation.py` | Builds the navigation index from `reading_order`, pulling every heading string verbatim out of the reviewed page JSON so the strings cannot drift, and failing loudly when a heading has no description. |
